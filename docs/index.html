🍓 MercApp - Frambuesa

Despliegue completo SPA + API propia + MongoDB Atlas

🌐 Enlaces del sistema

  • Frontend (Netlify): https://cozy-gecko-6801de.netlify.app
  • Backend API (Railway): https://mercapp-production-0628.up.railway.app/health
  • Repositorio GitHub: github.com/dnlbs/MercApp
  • Micrositio (esta página): https://dnlbs.github.io/MercApp/

🏗️ Arquitectura de despliegue

Frontend: Vue 3 + Vite → Netlify (CI desde GitHub)
Backend: Node.js + Express → Railway (con Nixpacks)
Base de datos: MongoDB Atlas (cluster M0 gratuito)
Documentación: GitHub Pages (carpeta /docs)
HTTPS: Activado en todos los servicios.

📦 Ejecución local

git clone https://github.com/dnlbs/MercApp.git
cd MercApp/backend
cp .env.example .env   # completar MONGODB_URI
npm install
npm run dev

# Otra terminal:
cd ../frontend
cp .env.example .env   # VITE_API_URL=http://localhost:3000
npm install
npm run dev
