📋 Descripción del Proyecto
Esta es una aplicación web de una sola página (SPA) para un emprendimiento Frambuesa de regalos y desayunos sorpresa. Permite gestionar un catálogo de productos, buscar y filtrar por categoría, ver detalles de cada producto, agregar al carrito y administrar productos (crear, editar, eliminar).

Tecnologías Utilizadas
Backend
Node.js + Express - Servidor API REST
Archivo JSON - Persistencia de datos
CORS - Comunicación con frontend
Frontend
Vue 3 - Framework progresivo
Vite - Build tool
Vue Router - Navegación SPA
Pinia - Estado global (carrito)
CSS puro - Estilos responsivos
